## 🧪 Labs & réalisations

**Réseaux & systèmes**
- 🔀 **Cisco** : VLAN, trunk et routage inter-VLAN, routage dynamique (RIP/OSPF), ACL, NAT/PAT, DHCP sur routeur.
- 🪟 **Domaine Active Directory** : AD + DNS + DHCP, organisation des objets, GPO, automatisation PowerShell.
- 🐧 **Services Linux** : DNS avec délégation, DHCP, serveur LAMP avec hôtes virtuels, FTP, serveur de messagerie SMTP/IMAP avec webmail, partages NFS.
- 📇 **Annuaire OpenLDAP** sécurisé en LDAPS (SSL/TLS).

**Sécurité**
- 🧱 **Politique de sécurité** : pare-feu Netfilter, routage filtrant, DMZ ; installation de **pfSense**.
- 🔐 **PKI & HTTPS** : autorité de certification et serveur HTTPS avec OpenSSL, entièrement en ligne de commande.
- 🕵️ **SSH MITM** : attaque *man-in-the-middle* sur OpenSSH (ssh-mitm, ettercap) et contre-mesures par authentification par clés.
- 🌐 **Proxy Squid** : filtrage web (HTTP/HTTPS) par ACL.
- 🛡️ **VPN SSL OpenVPN** : tunnel sécurisé via passerelle.
- 🔥 **UTM Stormshield** : mise en œuvre et configuration d'un pare-feu nouvelle génération.

**Supervision & conteneurs**
- 📈 **Zabbix** : supervision de l'infrastructure (hôtes, métriques, alertes).
- 🐳 **Docker Compose** : déploiement d'applications multi-conteneurs décrites dans un fichier Compose.

**Projets**
- ☁️ **Serveur de jeu sur GCP** : hébergement et exploitation pour un groupe d'amis (incidents disque, corruption de données, automatisation).
- 🏢 **Projet de professionnalisation** : équipe de 4 en méthode agile, dont j'assure la coordination.
- 💻 **Intranet PHP/MySQL** : développement en groupe d'une application web d'entreprise.
